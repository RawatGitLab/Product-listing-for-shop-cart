# 🛒✨ Product Listing & Shopping Cart 🛍️🚀

Welcome to **Product Listing & Shopping Cart**! A fast, modern, and interactive e-commerce shopping experience featuring dynamic product discovery, real-time cart management, and seamless responsive design. 💫🎉

---

## 🌟 Key Features

- 📦 **Dynamic Product Catalog**: Browse products with high-resolution imagery, pricing, ratings, and stock status.
- 🔍 **Instant Search & Filtering**: Filter by category, price range, and sort by relevance or popularity.
- 🛒 **Interactive Shopping Cart**:
  - ➕ / ➖ Adjust quantities on the fly with automatic subtotal updates.
  - 🗑️ Instant item removal and cart clearing.
  - 💰 Live calculation of subtotal, taxes, shipping, and total discounts.
- 💾 **Persistent Cart State**: Cart items persist across sessions using `localStorage`.
- 📱 **100% Responsive Design**: Optimized for mobile, tablet, and desktop screens with smooth micro-interactions.
- ⚡ **Snappy Feedback**: Toast alerts when items are added, updated, or removed.

---

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine:

### 📋 Prerequisites

Make sure you have Node.js and npm installed:

* 🟢 **Node.js** (v16.x or higher)
* 📦 **npm** or **yarn** / **pnpm**

### 💻 Installation

1. **Clone the repository** 📥
```bash
git clone [https://github.com/RawatGitLab/Product-listing-for-shop-cart.git](https://github.com/RawatGitLab/Product-listing-for-shop-cart.git)

```


2. **Navigate into the directory** 📂
```bash
cd Product-listing-for-shop-cart

```


3. **Install dependencies** 📦
```bash
npm install

```


4. **Start the development server** 🔥
```bash
npm run dev

```


5. **Open your browser** 🌐
Navigate to `http://localhost:5173` (or the port specified in your console).
